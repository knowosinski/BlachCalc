                        CO DZIEJE SIĘ NA BIEŻĄCO
════════════════════════════════════════════════════════════════════════════════

BUILD PROCESS:
  1. Uruchamia testy (run_tests.py)
  2. Sprawdza zależności (PyInstaller, PIL, openpyxl, etc.)
  3. Zamyka starą aplikację (jeśli działała)
  4. Tworzy ikonę (create_icon.py)
  5. Buduje binaria (PyInstaller) - NAJDŁUŻEJ
  6. Tworzy instalator (Inno Setup)
  7. Koniec!

CAŁE DANE ZAWSZE ZACHOWANE:
  • Baza danych: C:\Users\[Nazwa]\Documents\BLACHCALC\blachcalc.db
  • Oferty: C:\Users\[Nazwa]\Documents\BLACHCALC\OFERTY\
  • Wiecej: C:\Users\[Nazwa]\Documents\BLACHCALC\...

                        JEŚLI COS PÓJDZIE NIE TAK
════════════════════════════════════════════════════════════════════════════════

BŁĄD: "Cannot load file Build-Windows.ps1"
ROZWIĄZANIE: Otwórz PowerShell AS ADMINISTRATOR (patrz KROK 1)

BŁĄD: "python not found" lub brakuje zależności
ROZWIĄZANIE: Uruchom (w PowerShell):
  python -m pip install -r requirements-build.txt
  Potem spróbuj BUILD znowu

BŁĄD: "Inno Setup not found"
ROZWIĄZANIE: Pobierz i zainstaluj:
  https://jrsoftware.org/isdl.php
  Wybierz: Inno Setup 6 lub 7
  Potem spróbuj BUILD znowu

BUILD time exceeded
ROZWIĄZANIE: Czekaj dłużej (PyInstaller może trwać 20+ minut)
