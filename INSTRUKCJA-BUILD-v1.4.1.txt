🔧 JEŚLI COS PÓJDZIE NIE TAK

❌ BUILD FAILED (Błędy w testach)
   → Przeczytaj błąd w konsoli
   → Zwykle: brakuje zależności
   → Rozwiązanie: python -m pip install -r requirements-build.txt
   → Powtórz BUILD

❌ INNO SETUP NIE ZNALEZIONY
   → Zainstaluj: https://jrsoftware.org/isdl.php
   → Wybierz: Inno Setup 6 lub 7
   → Powtórz BUILD

❌ APLIKACJA NIE ZAMYKA SIĘ
   → BUILD czeka aż sam się zamknie
   → Zamknij ją ręcznie w tym czasie
   → Albo przycisk "Zamknij" w Build-Windows.ps1

❌ POWERSHELL MÓWI "CANNOT LOAD FILE"
   → Uruchom PowerShell AS ADMINISTRATOR
   → Powtórz komendę
