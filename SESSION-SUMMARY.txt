BŁĄD #1: TclError w _apply_sidebar_density()
------------------------------------------

Symptom: _tkinter.TclError: window "..." isn't packed
Lokacja: blachcalc.py, linie 1902-1920
Przyczyna: Race condition - widget spakowany, próba repakowania z innymi opcjami
Severidad: HIGH (crash przy resize)

Oryginalny kod (BŁĘDNY):
    if visible and not widget.winfo_manager():
        widget.pack(**options)  # ❌ TclError!

Naprawiony kod:
    if not widget.winfo_exists():  # ✅ Check existence
        continue
    try:  # ✅ Catch errors
        if visible and not widget.winfo_manager():
            widget.pack(**options)
        elif not visible and widget.winfo_manager():
            widget.pack_forget()
    except tk.TclError:  # ✅ Handle gracefully
        pass

Weryfikacja:
  ✅ 90-sekundowy stress test - BRAK błędów
  ✅ Resize okna - GŁADKI
  ✅ 256 testów - ALL PASS
